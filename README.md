# 自由效能进程EcoPilot v1.58 — 纯绿色效能模式管家

自由效能进程EcoPilot-netdna518。Windows 11 任务管理器「效率模式」的批量、可记忆版本。纯 Rust + Win32 原生界面，单文件绿色运行，带专属图标。程序属性（文件版本/产品名称/产品版本/版权）已写入 exe 资源。

## 纯绿色说明

- 全部配置只写在**程序目录**：`settings.json`（设置）和 `规则-xxxxxx.json`（每条规则一个文件，**直接放在程序文件夹里**，一眼就能看到）。
- **不写注册表、不写系统目录、不写 %APPDATA%**。程序启动时会一次性清除 v1/v2 遗留的注册表启动项。
- 开机自启：点工具栏「生成开机启动脚本」按钮，在程序目录生成 `开机启动-请复制到启动文件夹.bat`（中文文件名，内容为纯 ASCII + `%~dp0` 相对路径，不会乱码），并弹出完整复制说明。右侧还有「所有用户启动文件夹」「当前用户启动文件夹」两个按钮，点一下直接用资源管理器打开对应目录，把 bat 复制进去即可；带 `--apply --tray` 参数。

## 界面

**左侧进程列表**：**每个进程名前面带该程序的小图标**（像任务管理器，从可执行文件提取，按路径缓存不重复加载）、PID、CPU、内存、磁盘、网络、效能模式、路径。搜索实时过滤并定位；点列头排序（效能列按「已效能→内置/用户保护→普通」聚集）；双击切换效率模式。

效能模式列区分：`已效能` / `内置保护` / `用户保护` / `普通`。内置保护是程序自带的关键系统进程名单，用户保护是你在设置或右键里加入的，二者显示不同文字。

**右上：当前效能进程** —— 节点前 `+/-` 可展开折叠（单击生效），列出所有效能进程；右键节点「移除效能模式」单独移除，或「移除所有进程的效能模式」。

**右下：规则树** —— 节点前 `+/-`，显示规则名与成员数，**默认展开**且展开状态不受自动刷新影响；展开后显示每个成员进程及状态（如 `chrome.exe PID 2660 效能中`）。规则区下方有「新建规则」「重命名规则」按钮，右键规则也有对应菜单。

点右侧树里的进程节点只在左侧选中，**不会刷新整个列表**（不闪）。

**顶部按钮**（与菜单功能一致）：刷新、设为效能模式、移除效能模式、加入规则、立即应用规则、移除所有效能、自动刷新开关、设置、退出。

**CPU 占用**：界面显示时按自动刷新间隔（默认 5 秒）采样一次，**缩到托盘/隐藏窗口时定时器彻底停止，CPU 占用为零**（实测隐藏状态 6 秒 CPU 增量 0 秒）。设置里的「定时自动刷新进程列表」开关可完全关闭周期性采样；关闭后界面显示时也不再自动刷新，需点「刷新」按钮手动更新。

**应用失败怎么办**：点"立即应用规则"后，如果有进程失败（多是瞬时进程刚退出、或权限不足），会弹出**失败进程清单**：进程名、PID、所属规则、失败原因，默认全部勾选。点「从规则移出勾选的进程」即可把这些成员从规则里删掉，以后不再尝试。找不到列表里的 PID 是正常的——进程已退出，列表是每 5 秒的快照。

重命名/删除规则时会自动同步 settings.json 里的自动应用规则列表——改名后不用再进设置点确定。「启动自动应用」「应用成功后退出」两项只在设置对话框里（设置即时写盘，无需点确定后才生效的误解已消除）。

**运行权限**：程序以 `asInvoker` 运行（exe 内嵌 manifest），不请求管理员。对某些系统进程设置/移除效能会被拒绝（弹"部分失败"），这是权限限制，不是程序错误；开机静默应用场景也依赖不弹 UAC。

**字体**：设置对话框和「关于」对话框都比系统默认大一号，长说明完整换行显示。设置里"定时自动刷新"排在"启动自动应用"之前，"应用成功后退出"作为子选项缩进紧跟其后。

## 规则模型

点「加入规则」不会自动建规则——弹对话框让你选加入已有规则或新建规则。一条规则可含多个进程，`rules` 数组在 JSON 里：

```json
{
  "name": "笔记本使用",
  "members": ["alg.exe", "Boom3D.exe"],
  "path": "",
  "match_path": false,
  "enabled": true,
  "restore_priority": 32,
  "note": ""
}
```

文件名即 `规则-笔记本使用.json`。程序目录里有几个 `规则-*.json` 就载入几条规则。

## 设置对话框

- 生成开机启动脚本 / 启动时缩到托盘 / 托盘图标 / 启动自动应用规则
- **自动应用规则成功后自动退出本程序**：登录时静默套用规则、成功后直接退出，不留后台进程。启动本选项后就看不到程序界面了，想改回来，用记事本打开程序目录里的 `settings.json`，把 `"exit_after_apply": true` 中的 `true` 改成 `false`
- 启动时应用哪些规则：勾选指定几条，全不勾 = 全部启用规则
- **关闭按钮缩到托盘**：点 X 只隐藏窗口，托盘图标右键「退出」才真正退出

## 命令行

```text
EcoPilot.exe                 启动界面
EcoPilot.exe --selftest      自检 EcoQoS
EcoPilot.exe --list          列出进程及效能状态
EcoPilot.exe --apply         应用规则后启动界面
EcoPilot.exe --apply --tray  应用规则后仅在托盘运行
```

## 保护名单

内置：csrss、wininit、winlogon、services、lsass、svchost、dwm、System、MsMpEng 等（状态列显示「内置保护」）。用户自定义在 settings.json 的 `protected` 数组，或右键加入（显示「用户保护」）。两类都不会被设为效能模式。

## 从源码构建

需要 Rust（推荐 `stable-x86_64-pc-windows-gnu`）与 MinGW-w64 的 `windres`（用于编译图标与版本资源 `app.rc`）。

```bat
:: 若 windres 不在 PATH，可先设置：set WINDRES=C:\path\to\windres.exe
build.bat
:: 产出：EcoPilot.exe（256 位 MD5 见发布页）
```

找不到 windres 时构建仍会成功，只是 exe 没有自定义图标和版本信息。核心功能无第三方 crate 依赖（Win32 API 手动声明）。
