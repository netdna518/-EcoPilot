1什么是效能模式

效能模式（Efficiency mode）是 Windows 10 1709 之后内置的能力，本质上同时做两件事：把进程的优先级降为「空闲」，并打开 EcoQoS（让 CPU 调度优先采用节能运行状态）。它不会关闭程序，只是让这个程序「更懂事地让出资源」。

降低 CPU 资源消耗

降低进程争夺 CPU 的优先级，减少不重要的后台程序对 CPU 的干扰，让前台正在使用的软件更容易拿到资源。

降低功耗和发热

通过 EcoQoS 引导 CPU 优先运行在节能状态，减少不必要的高性能运转，降低功耗与温度——笔记本上能明显延长续航。

改善前台程序体验

多个程序同时运行时，后台不再抢 CPU，前台程序更少卡顿，多任务切换更跟手。

减少后台程序干扰

后台浏览器标签页、暂时不用的软件、后台数据处理、不需即时响应的辅助程序，都会主动让出 CPU。

降低整机能效开销

多个后台进程开启后，整体 CPU 能耗下降，减少处理器高频运行，散热负担变轻——风扇噪声也会随之减小（视硬件与负载而定）。

一句话理解：效能模式不是「冻结」程序，而是告诉系统「这个程序不着急，资源先紧着别人」。它照常运行，只是不再抢跑。

2为什么需要自由效能进程EcoPilot

Windows 自带的效率模式好用，但只在任务管理器里能点，而且每次开机都要重新点一遍——进程一多就很麻烦。自由效能进程EcoPilot 就是为了解决这个重复劳动。

对比任务管理器手动设置自由效能进程EcoPilot

记忆能力重启程序后设置失效规则保存在程序目录，长期有效
开机自动做不到生成启动脚本，登录时静默自动应用

附带开销—纯绿色单文件，隐藏时 CPU 占用为零
适合谁：笔记本续航焦虑者、后台常开一堆软件的人、希望前台游戏/办公更流畅的人、想让电脑更安静的人。

3快速上手

运行程序。双击 EcoPilot.exe，无需安装。主界面分三块：左侧进程列表、右上「当前效能进程」、右下「规则」。
找到要处理的进程。在左侧搜索框输入进程名关键字，列表实时过滤并定位；也可以点列头排序。
设为效能模式。勾选一个或多个进程，点顶部「设为效能模式」；或者直接双击某个进程切换它的效能状态。
想建规则就点「加入规则」。把常用后台软件归到一条规则里，以后点「立即应用规则」一次搞定。
想开机自动，进「设置」。勾上「启动/进入时自动应用规则」，点工具栏「生成开机启动脚本」生成 bat 和快捷方式，把其中一个放进启动文件夹即可（两者都指向真实程序名、带静默参数）。
核心系统进程受保护：csrss、wininit、winlogon、services、lsass、svchost、dwm、System、MsMpEng 等内置保护名单里的进程不会被设为效能模式，状态列会显示「内置保护」。你也可以在设置或右键里添加自己的保护名单。

4界面与按钮

左侧 · 进程列表

每个进程名前带该程序的小图标（像任务管理器一样从可执行文件提取），显示 PID、CPU、内存、磁盘、网络、效能状态与路径。状态列分为 已效能 / 内置保护 / 用户保护 / 普通。

右上 · 当前效能进程

列出所有已被效能化的进程。节点前的 + / − 可展开折叠；右键节点可单独「移除效能模式」或「移除所有进程的效能模式」。

右下 · 规则树

显示每条规则的名字与成员数，默认展开。展开后能看到每个成员进程及其状态，例如 chrome.exe PID 2660 效能中。右键规则可新建、重命名、移出成员。

顶部工具栏

刷新 (F5) 设为效能模式 移除效能模式 加入规则 立即应用规则 移除所有效能 自动刷新：开/关 生成开机启动脚本 所有用户启动文件夹 当前用户启动文件夹 设置 退出

低占用设计：界面显示时按自动刷新间隔（默认 5 秒）采样一次；缩到托盘或隐藏窗口后定时器彻底停止，CPU 占用为零。设置里的「定时自动刷新」开关可以完全关闭周期性采样。

5规则：一劳永逸

规则就是「一组进程 + 一个名字」。程序目录里每个 规则-xxx.json 文件就是一条规则，有几个文件就有几条规则。

{
  "name": "功能类",
  "members": ["chrome.exe", "Boom3D.exe"],
  "path": "",
  "match_path": false,
  "enabled": true,
  "restore_priority": 32,
  "note": ""
}
  • 点「加入规则」不会自动建规则，而是让你选择加入已有规则或新建规则。
  • 一条规则可含多个进程；enabled 为 false 时该规则不参与自动应用。
  • 重命名 / 删除规则时，程序会自动同步配置里引用的规则名，不会出现「名字对不上」导致自动应用失效。
应用失败怎么办：点「立即应用规则」后若有进程失败（多为瞬时进程刚退出或权限不足），会弹出失败清单：进程名、PID、所属规则、原因，默认全选。点「从规则移出勾选的进程」即可把它们从规则里删掉，以后不再尝试。

6开机自动挡

让效能模式在每次登录时自动生效，全程看不到程序界面、应用完就退出。

在设置里勾选两项。「启动/进入时自动应用规则」+「自动应用规则成功后自动退出本程序（静默后台模式）」。
指定要应用的规则。设置里「启动时应用哪些规则」勾选指定几条；全不勾表示应用全部启用规则。
生成启动文件。点工具栏「生成开机启动脚本」，程序会在自身目录生成两个文件：真实程序名+开机启动-请复制到启动文件夹.bat 和 真实程序名+开机启动-请复制到启动文件夹.lnk（快捷方式），例如 自由效能进程EcoPilot-v1.58开机启动-请复制到启动文件夹.lnk。两者都自动指向当前真实的程序文件名（程序改名也能正确找到），并带 --apply --tray 静默参数，弹出说明。
放进启动文件夹。点旁边「所有用户启动文件夹」或「当前用户启动文件夹」按钮打开对应目录，把 bat 或快捷方式复制进去（任选其一，推荐快捷方式更美观）。也可按 Win + R 输入 shell:startup 快速打开当前用户的启动文件夹。
效果：下次登录时，程序在后台按规则应用效能模式，完成后立即退出，不留后台进程、不弹界面。这样你开机后那些常驻的后台软件就已经处于低耗状态了。
想改回来：静默模式看不到界面。用记事本打开程序目录里的 settings.json，把 "exit_after_apply": true 里的 true 改成 false，保存后再启动程序就能看到界面了。（在设置里点确定只保存配置、不会当场重新应用规则。）

8绿色与安全

  • 全部配置只在程序目录：settings.json（设置）和 规则-*.json（每条规则一个文件，直接放在程序文件夹里，一眼可见）。
  • 不写注册表、不写系统目录、不写 %APPDATA%。程序启动时会一次性清除旧版遗留的注册表启动项。
  • 不请求管理员权限：以 asInvoker 运行，不弹 UAC。对少数系统进程设置/移除效能会被拒绝（弹「部分失败」），这是正常的权限限制，不影响其他进程。
  • 可回滚：任何效能设置都能用「移除效能模式」或「移除所有效能」还原为普通优先级。

命令行

EcoPilot.exe                 # 启动界面
EcoPilot.exe --selftest      # 自检 EcoQoS 是否可用

9常见问题

任务管理器里看，效能好像没生效？

用命令行 EcoPilot.exe --list 查看最可靠，状态列显示「效能中」即为已生效。任务管理器的列可能有刷新延迟，需要重新打开或等待刷新。

某些进程设置失败？

常见原因：进程是瞬时进程、刚好退出、或权限不足。失败的进程会在失败清单里列出，可一键从规则移出。内置保护名单里的系统进程是故意跳过的。

静默启动后看不到界面，怎么改设置？

按上文「开机自动挡」里的方法，编辑 settings.json 把 exit_after_apply 改为 false。

效能模式会不会让程序停止工作？

不会。它只降低优先级和切换 EcoQoS，程序照常运行；前台需要它时系统会正常调度。真正需要强响应的程序，别加入规则即可。

关闭窗口是退出程序吗？

在设置里可开启「关闭按钮缩到托盘」：点 X 只隐藏窗口，托盘图标右键「退出」才真正退出。
